# Quick Lead Sheet — Backing Generator

コード進行とテンポを入力するだけで、リードシートとピアノバッキング譜面を自動生成するツール。
セッションでのオリジナル曲共有や、コード譜が苦手なキーボーディストのサポートに。

## 起動

```bash
npm install
npm run dev
```

http://localhost:5173 を開く。

## 新機能(v0.5)

- **自動保存** — 編集内容はlocalStorageに常時保存され、次回起動時に復元される
- **Share** — 右上のShareボタンで、曲とすべての設定を含むURLをコピー。開くだけで同じ状態が再現される
- **Transpose** — ♭/♯ボタンで全コード+キーを半音単位で一括移調(記法マーカーは保持)
- **セクション** — `# Verse` のような行がセクションラベルとして譜面に印字され、そこで改行される
- **ハーモニー分析器**(harmony.ts) — キー推定(ダイアトニック適合+ケーデンス検出)→ 機能分析(セカンダリードミナント/裏コード/バックドア/経過ディミニッシュ)→ コードスケール決定 → **テンションとアヴォイドノートを自動選択**。例: C調の A7→Dm7 は自動でb9/b13系のオルタードカラーに、IVmaj7は#11に。ユーザーが明示したテンションは常に優先
- **Grand音色** — Salamander Grand Piano(Alexander Holm氏, CC-BY-3.0, Tone.js CDN経由)のサンプルを遅延ロード。ロード完了まではFM合成でフォールバック

## 使い方

1. **Chords** にコード進行を入力
   - `|` で小節区切り、1小節に1〜4コード、`%` で前小節の繰り返し
   - 対応コード例: `Cmaj7` `F#m7b5` `Bb7#9` `C/E` `G7sus4` `Dm9` `C6/9` `A7alt` `Bdim7` など
   - **食い(アンティシペーション)**: `^Cmaj7`=16分食い / `>Cmaj7`=8分食い / `>>Cmaj7`=4分食い。
     前の小節から食ってコードチェンジし、タイで持ち越す
   - **`G7!`** — キメ(スタブ)。短いアクセントで全パートが合わせて休む
   - **`[3-3-10] Cmaj7`** — 小節にキメのリズムを適用(両手リズムユニゾン)。
     **16分音符の長さを `-` で並べる**(合計16まで、余りは休符)。タ・・タ・・ター = `[3-3-10]`、
     ロック定番のダブルトレシロ = `[3-3-2-3-3-2]`、4分4つ = `[4-4-4-4]` など自由。
     `charleston` / `clave` という名前や旧表記 `335` `3322` も使える。
     リードシートにも実際のリズムで記譜される
   - フィギュア小節では**ヒットごとに**コードを書ける: `[3-3-10] Cmaj7 Cmaj7 Bm7` = 1・2打目がCmaj7、3打目(ター)がBm7。
     コードがヒット数より少ないときは最後のコードが残りを埋める
2. **Style** を選択 — Jazz / Neo-Soul / Pop / Ballad。選択時に Groove 設定が初期化される
3. **Groove** で細かく調整
   - **Feel**: Swing 8ths / Straight 8ths / 16 Beat / Shuffle 16ths(16分シャッフル。ハーフタイムシャッフルにしたい時はこれ+Density低め+テンポ半分)
   - **Swing**: スウィングの深さ(50%=ストレート 〜 75%)
   - **Density**: リズムの手数 / **Tension**: ボイシングの厚み(Basic / +9th / Rich)
   - **Register**: 右手ボイシングの音域 / **Push 食い**: 小節頭のコードチェンジを自動で食う確率
   - **Humanize**: ベロシティ・タイミングの揺れ
   - **Embellish**: 内声クリシェ(9→3、4→3、maj7→6)を自動で入れる確率。エレピらしい「指が動く」伴奏になる
     (譜面はシンプルさ優先で基本形のまま。動きは再生とMIDIに反映)
   - **Fill オブリ**: コードチェンジ直前のスキマに、次のコードのトップノートへ向かうピックアップ・ラン
     (コードトーン+半音/全音アプローチ)を自動挿入する確率。スウィング系は8分、16系は16分で走る。**Fill Style** で語彙を選択:
     Basic(コードトーン+半音アプローチ)/ Blues(ブルーノート入りのラン)/ Gospel(ペンタ+3度ダブルストップ)/
     Jazz(ビバップの囲い込みアプローチ)/ Contemporary(ペンタの4度スキップ+4度ダブルストップ)/ Mix。
     フィルはピアノ譜にも記譜される(直前まで押さえていたコードはフィルの位置で切る=実際の弾き方どおり)。
     トランスポートの **Fills譜** トグルで「オブリ込みの譜面/クリーンな譜面」を切り替えられる
     (再生・MIDIには常に含まれる。生成自体を無くすときは Fill ノブを0%に)
4. **Sound**(トランスポート内)で音色を選択(再生中でも切替可)
   - **Grand** — サンプルベースのアコースティックグランド(Salamander Grand Piano / CC-BY-3.0)。初回選択時に遅延ロード
   - **Suitcase** — 温かいクラシックローズ(FM)
   - **Neo Soul** — 角の丸い鋸歯(サイン波を Bend +/- した Serum 系レシピの再現)。ネオソウル定番のキーズ
   - **Wurli** — 枯れたバークのウーリッツァー
   - **8-Bit** — ファミコン仕様: 右手=デューティ比25%のパルス波、左手=三角波ベース、音量4段階量子化
5. ▶ で再生確認(現在の小節をハイライト)。Click でメトロノーム。Regenerate でパターンを引き直し
6. **Export**
   - **MIDI** — 右手/左手の2トラック構成のSMF(グルーヴのタイミング込み)。DAWにそのまま読める
   - **PNG** — 表示中の譜面を画像保存(リードシートはジャズフォント埋め込み)
   - **PDF** — ブラウザの印刷ダイアログから保存

## 技術構成

- Vite + React + TypeScript
- 譜面描画: VexFlow — ピアノ譜は Bravura、リードシートは Petaluma(手書きジャズ譜フォント)+ PetalumaScript
  (リズム分解・タイ・小節跨ぎタイ・休符・調号スペリングは自作の `notation.ts`)
- 再生: Web Audio API 自作FMエレピ音源 — タイン(ベル)成分 + ステレオトレモロ + コーラス + リバーブ(`audio.ts`)
- ボイスリーディング: 前のボイシングからの声部移動コスト最小化 + 共通音維持(`styles.ts`)
- MIDI: 自作 SMF Format 1 ライター(`midi.ts`)
- コード解析/生成: `theory.ts` / `generate.ts`

`scripts/test-midi.ts` で生成〜MIDI出力のサニティテストが実行できます:

```bash
npx esbuild scripts/test-midi.ts --bundle --platform=node --format=cjs --outfile=scripts/test-midi.cjs && node scripts/test-midi.cjs
```
